# Directory Submissions

Create optimized listings for directory and review site submissions for: **$ARGUMENTS**

## What This Skill Does

Write directory listings that rank well within the directory, convert browsers to visitors, and maintain consistent brand messaging across every submission platform.

## Process

### 1. Identify Target Directories

Categorize by type and generate a submission list:

**General Product Directories**
- Product Hunt, AlternativeTo, Capterra, G2, Trustpilot, GetApp

**Niche / Vertical Directories**
- SaaS-specific: SaaSHub, SaaSworthy, Slant
- Developer tools: DevHunt, ToolsFinder
- AI tools: There's An AI For That, Futurepedia, AI Tools Directory
- Industry-specific: identify 3-5 directories specific to $ARGUMENTS vertical

**SEO-Focused Directories**
- Crunchbase (DA 90+), AngelList, LinkedIn Company Page
- Indie Hackers, BetaList (for early-stage)

### 2. Core Listing Assets

Write once, adapt for each directory:

**Product Name**
Exact brand capitalization — verify it's consistent everywhere.

**Tagline (under 60 chars)**
Primary keyword + core value prop. No punctuation at end.

**Short Description (150-200 chars)**
One sentence: who it's for + what it does + key outcome.

**Long Description (500-800 words)**
Structure:
- Paragraph 1: The problem and why existing solutions fall short
- Paragraph 2: What the product does and how it works
- Paragraph 3: Key features (bulleted, benefit-framed)
- Paragraph 4: Who uses it and what results they get
- Paragraph 5: Pricing/how to get started + CTA

**Categories and Tags**
List 10 relevant tags/categories — use the platform's own taxonomy when possible.

### 3. Review Generation

For sites like G2 and Capterra:
- Email satisfied users with direct review link and specific ask ("Would you share what problem we helped you solve?")
- Time the ask post-success moment (after first value, not immediately after signup)
- Respond to every review within 48 hours (shows platform engagement)

## Output

Deliver: submission target list (prioritized by DA/traffic), all core listing copy in ready-to-paste format, and a review generation email template.
