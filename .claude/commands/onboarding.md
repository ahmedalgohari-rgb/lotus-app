# Onboarding

Design and write user onboarding flows for: **$ARGUMENTS**

## What This Skill Does

Build onboarding that gets users to their first value moment as fast as possible — then reinforces the habit until they're retained.

## The Onboarding Goal

The only job of onboarding: get the user to the "aha moment" before they give up.

The aha moment is the specific action that correlates most strongly with retention. Every onboarding step that doesn't lead toward the aha moment is friction.

## Onboarding Design Process

### 1. Identify the Aha Moment

For $ARGUMENTS, define:
- What is the single action that, once taken, means users are highly likely to stick?
- How long does it currently take new users to reach it?
- What is the shortest possible path to it?

### 2. Map the Current Flow

List every step from signup to aha moment:
1. [Step] — why it exists — can it be removed or deferred?

Apply: "Could we defer this until after the aha moment?" to every step. If yes, move it.

### 3. Progressive Disclosure

Don't teach everything upfront. Sequence learning to match the user's readiness:
- **Before aha**: only what's needed to reach it
- **At aha**: celebrate, reinforce what they just felt
- **After aha**: teach the next layer, now that they're invested

### 4. Onboarding Patterns to Use

**Empty state design** — the screen before a user has data should not feel broken; it should demonstrate the end state and invite action

**Checklist / progress** — shows users what's possible and gamifies setup completion

**Tooltips and spotlights** — show features in context, not in a separate tutorial

**Contextual prompts** — trigger help at the moment of confusion, not before it

### 5. Onboarding Copy

Write copy for each step:
- **Screen title**: what the user does, not what the product offers
- **Body copy**: one benefit sentence maximum
- **CTA**: action verb + specific outcome (not "Continue")
- **Skip text**: honest ("I'll set this up later") not dismissive ("Skip")

### 6. Email Onboarding Sequence

Days 1, 3, 7, 14 — for users who didn't reach the aha moment in-app:
- Subject: specific to where they stopped
- Body: one re-engagement action
- CTA: deep-link to the exact step they need

## Output

Deliver: aha moment definition, simplified flow map, screen-by-screen copy, and 4-email onboarding drip sequence.
