# Optimize

Optimize content, performance, or strategy for maximum impact for: **$ARGUMENTS**

## What This Skill Does

Take something that works and make it work significantly better — through systematic analysis, prioritized improvements, and clear measurement of progress.

## Optimization Mindset

Optimization is not "make it better generally." It is:
1. Define a specific metric to improve
2. Identify the biggest lever affecting that metric
3. Change one thing, measure, learn, repeat

Without a metric, optimization is just editing.

## Process

### 1. Define the Optimization Target

- What is the metric? (conversion rate, page load time, open rate, retention, NPS)
- What is the current baseline?
- What is the goal?
- What is the timeframe?

### 2. Identify Constraints

- What can't change? (brand guidelines, technical limits, budget)
- What's already been tried?
- What data exists to inform decisions?

### 3. Opportunity Analysis

Rank improvement opportunities by:
- **Impact**: how much could this move the target metric?
- **Confidence**: how sure are we this will work?
- **Effort**: how hard is it to implement?

Score each: ICE = (Impact + Confidence + Effort) / 3
High ICE scores = do first.

### 4. Specific Optimizations

For $ARGUMENTS, analyze and provide:

**If content**: headline testing, structure, CTA placement, length, format
**If UX/UI**: friction removal, visual hierarchy, mobile behavior, load states
**If ads/email**: targeting, creative, subject lines, send time, frequency
**If SEO**: keyword targeting, page structure, internal linking, meta tags
**If product**: activation flow, feature discoverability, habit triggers

### 5. Implementation Order

1. Highest ICE score first
2. Changes that unblock other changes
3. Quick wins that build momentum

### 6. Measurement Plan

For each optimization:
- What metric changes if this works?
- How long to see signal? (statistical significance)
- What's the success threshold?

## Output

Deliver: current state analysis, ranked opportunity list (ICE scored), specific changes for top 5 opportunities, and a measurement plan.
