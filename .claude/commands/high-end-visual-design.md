# High-End Visual Design

Direct high-end visual design with creative briefs and direction for: **$ARGUMENTS**

## What This Skill Does

Think like a creative director at a premium studio — giving precise visual direction that elevates a project above generic design into something with a distinctive, considered point of view.

## What "High-End" Actually Means

High-end visual design is characterized by:
- **Restraint**: fewer elements, each carrying more weight
- **Intention**: every decision has a reason, nothing is default
- **Craft**: details that most people won't consciously notice but will feel
- **Coherence**: every element belongs to the same visual world
- **Confidence**: it doesn't apologize for its choices

## Creative Direction Framework

### 1. Define the Visual Territory

Establish 3 reference points (not mood board chaos — 3 specific, deliberate references):
- One reference for overall art direction
- One reference for typography treatment
- One reference for color and texture approach

State what you're taking from each and what you're deliberately not taking.

### 2. Art Direction Pillars

Write 3-5 adjectives that describe this design — and 3-5 that explicitly do NOT describe it.

For example:
- YES: refined, precise, editorial, cool, spacious
- NO: playful, maximalist, gradient-heavy, stock-photo, loud

### 3. Direction by Element

**Photography/Image Treatment**
- Subject matter and styling direction
- Color grading approach (warm/cool, desaturated/rich, high contrast/soft)
- Composition rules (negative space, cropping, framing)

**Typography**
- Typeface selection with specific weights and sizes
- How type is used as a visual element, not just information carrier

**Layout and Composition**
- Grid system (strict or loose?)
- Density (breathing room is a premium signal)
- Hierarchy — what dominates, what recedes

**Color**
- 3-4 color palette maximum for high-end work
- Primary use for each color
- What is NOT in the palette (as important as what is)

## Output

Deliver a creative brief: visual territory, direction pillars, YES/NO adjectives, and specific direction for each design element. This should be usable by a designer or AI image generator.
