# Bolder

Rewrite content to be bolder, more confident, and punchier: **$ARGUMENTS**

## What This Skill Does

Strip out hedging language, weak qualifiers, and passive constructions. Replace them with direct, assertive, memorable statements that command attention.

## Rewriting Rules

### Remove Immediately
- "We think / we believe / we feel" — you either know or you don't
- "Kind of / sort of / a bit / somewhat / fairly" — weasel words
- "Try to / aim to / hope to" — commit or don't
- "Solutions / offerings / leverage / utilize" — corporate mush
- Passive voice: "is designed to" → "does"
- Throat-clearing intros: "In today's world..." / "Now more than ever..."

### Replace With
- Active verbs: present tense, first person, direct object
- Concrete claims: specific numbers, named outcomes
- Short sentences: under 12 words hits harder
- Commands: "Get X" beats "You can get X"
- Contrast: "Most tools do X. We do Y."

### Boldness Levels

Apply based on $ARGUMENTS or default to Level 2:

- **Level 1** — Remove hedging only, keep tone professional
- **Level 2** — Sharpen claims, tighten sentences, punch up CTA
- **Level 3** — Provocative, opinionated, willing to alienate the wrong audience to resonate with the right one

## Output Format

Show original and rewritten versions side by side for each block:

```
ORIGINAL
[original text]

BOLDER
[rewritten text]

WHAT CHANGED
- Removed: [hedging phrases cut]
- Added: [stronger elements]
- Tone shift: [description]
```

If rewriting a full page or document, rewrite in full then summarize changes at the end.
