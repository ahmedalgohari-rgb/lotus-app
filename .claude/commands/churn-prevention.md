# Churn Prevention

Develop strategies and messaging to reduce user churn for: **$ARGUMENTS**

## What This Skill Does

Identify churn signals, design intervention points, and write the messages that bring users back or keep them from leaving.

## Process

### 1. Diagnose Churn Causes

Classify churn into categories:
- **Activation failure** — never got value, churned in first 7 days
- **Engagement decay** — used it, drifted away, didn't make it a habit
- **Value gap** — feature they needed doesn't exist
- **Competitive loss** — switched to a specific competitor
- **Price sensitivity** — can't justify cost vs. perceived value
- **Life event** — need temporarily gone (seasonal, role change, project end)

Ask: Which category does $ARGUMENTS fall into? What evidence supports this?

### 2. Map the Churn Timeline

Identify the signals that appear before churn, in order:
1. Leading indicators (usage drop, feature abandonment, support tickets)
2. Warning signals (login frequency decline, skipped renewal prompts)
3. Churn event (cancellation, inactivity threshold crossed)

### 3. Design Intervention Moments

For each churn stage, prescribe a specific intervention:

| Signal | Trigger | Message Type | Channel |
|--------|---------|-------------|---------|
| No action in 3 days | Day 3 | Activation nudge | Push/email |
| Feature unused | Day 7 | Tutorial offer | In-app |
| 2-week silence | Day 14 | Win-back + value recap | Email |
| Cancellation intent | Cancel flow | Pause offer / exit survey | Modal |
| Post-cancel | Day 30 | Re-engagement | Email |

### 4. Write the Messages

For each intervention, write:
- Subject line / push title
- Body copy (2-4 sentences max — shorter wins)
- CTA (one action, specific)
- Personalization tokens to use

### 5. Structural Fixes

Beyond messaging, flag product or pricing changes that would structurally reduce churn:
- Onboarding gaps to fix
- Missing features driving loss
- Pricing tier misalignment
- Habit-forming mechanics to add

## Output

Deliver a churn prevention playbook: diagnosis, intervention map, message copy for each touchpoint, and 3 structural recommendations.
