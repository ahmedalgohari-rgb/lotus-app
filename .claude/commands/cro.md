# CRO — Conversion Rate Optimization

Analyze and optimize conversion rates for: **$ARGUMENTS**

## What This Skill Does

Identify the specific friction points, trust gaps, and messaging failures that prevent visitors from converting — and prescribe fixes ranked by expected lift.

## Process

### 1. Define the Conversion Event

- What action counts as a conversion? (signup, purchase, trial start, demo request, download)
- What is the current conversion rate?
- What is the target or benchmark?
- What is the value of each conversion? (LTV, revenue, or proxy metric)

### 2. Map the Conversion Path

List every step a user takes from entry to conversion:
1. [Entry point] → 2. [Page/screen] → ... → N. [Conversion event]

For each step, estimate or request:
- Drop-off rate
- Time spent
- Common exit paths

### 3. CRO Audit by Page Element

Evaluate each element against conversion best practices:

**Above the Fold**
- Is the value proposition clear in under 5 seconds?
- Is the primary CTA visible without scrolling?
- Does the headline speak to the visitor's job-to-be-done, not the product's features?

**Trust Signals**
- Social proof visible early? (numbers, logos, testimonials)
- Risk reversal present? (free trial, money-back, no credit card)
- Security signals? (SSL, compliance badges if relevant)

**CTA Optimization**
- Is there one primary CTA per page or is attention split?
- Is button text specific? ("Start Free Trial" beats "Submit")
- Does CTA color contrast sufficiently with background?

**Form Friction**
- Fields: are all required fields actually required?
- Error messages: are they specific and helpful?
- Progress indicators for multi-step flows?

**Page Speed**
- Images optimized?
- Core Web Vitals acceptable? (LCP < 2.5s, CLS < 0.1)

### 4. Prioritized Recommendations

For each issue found:
- **Expected lift**: low / medium / high
- **Implementation effort**: low / medium / high
- **Specific change**: what exactly to do

## Output

Deliver a prioritized CRO fix list, starting with highest impact/lowest effort items. Include at least one A/B test hypothesis for the top finding.
