# Free Tools

Ideate and build free tool concepts for lead generation for: **$ARGUMENTS**

## What This Skill Does

Design free tools (calculators, generators, checkers, templates) that attract the exact audience who would pay for the core product — turning SEO traffic into qualified leads.

## What Makes a Great Free Tool

- Solves a real problem the target user has right now
- Delivers value in under 60 seconds (no signup required)
- Naturally leads to the next problem that the paid product solves
- Is specific enough to rank for a long-tail keyword
- Is shareable — people send it to colleagues or post it

## Process

### 1. Ideation

For $ARGUMENTS, generate 10 free tool ideas using these patterns:

**Calculator** — "How much X do I need?" / "What's my ROI from Y?"
**Checker / Auditor** — "Is my X healthy?" / "What's wrong with my Y?"
**Generator** — "Write X for me" / "Create a Y template"
**Converter** — "Turn X into Y format"
**Analyzer** — "Tell me what my X means"
**Planner** — "Help me plan X"

For each idea, specify:
- Tool name
- What input the user provides
- What output they receive
- How it connects to the paid product
- Target keyword for SEO
- Estimated build complexity (low/medium/high)

### 2. Prioritization

Score each tool:
- Search demand (does this keyword have volume?)
- Qualification quality (does this attract ideal customers or just anyone?)
- Paywall moment (how naturally does it prompt upgrade?)
- Build cost (how long to build?)

### 3. Build Specification

For the top 2-3 tools, write a build spec:
- Inputs (fields, types, validation)
- Processing logic (formula, API, or rules)
- Output format (table, chart, text, download)
- Email capture moment (gate the full report, not the tool)
- CTA after completion ("See how [product] can automate this")

### 4. Landing Page Copy

For each tool:
- Page title (include keyword)
- H1 + subhead
- Tool description (what it does in 2 sentences)
- Below-tool CTA to paid product

## Output

Deliver 10 tool ideas with scores, full spec for top 3, and landing page copy for the #1 pick.
