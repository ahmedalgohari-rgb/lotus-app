# Adapt

Adapt content for a different audience, platform, or context: **$ARGUMENTS**

## What This Skill Does

Transform existing content so it lands correctly for a new context — without losing the core message.

## Process

### 1. Identify What's Changing

Determine the adaptation axis:
- **Audience**: expert → beginner, B2B → consumer, US → international, adult → teen
- **Platform**: long-form → tweet thread, blog → LinkedIn, video script → email
- **Tone**: formal → casual, serious → playful, corporate → personal
- **Length**: full article → TL;DR, pitch deck → one-pager, email → SMS
- **Language/Culture**: localization, idiom replacement, cultural reference swaps

### 2. Identify What Must Stay

- Core message or value proposition
- Key facts, data points, or claims that can't be changed
- Brand voice guardrails
- Any legal or compliance language

### 3. Adapt

Apply the transformation:
- Adjust vocabulary to match audience's fluency level
- Restructure for the platform's consumption pattern (scroll, skim, read)
- Replace jargon, idioms, or references that won't translate
- Re-sequence information for the new context's expectations
- Trim or expand to fit the format's natural length

### 4. QA the Adaptation

Check:
- Does the core message survive intact?
- Would the target audience immediately understand this?
- Are there any awkward holdovers from the original format?
- Does it feel native to the new platform, not just reformatted?

## Output

Provide the adapted content in full, followed by a brief note on the key changes made and any trade-offs.
