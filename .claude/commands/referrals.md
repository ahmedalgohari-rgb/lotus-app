# Referrals

Design referral programs and write referral copy for: **$ARGUMENTS**

## What This Skill Does

Build referral programs that spread because the incentive structure is right, the ask is well-timed, and the copy makes sharing feel natural — not like work.

## Why Most Referral Programs Fail

- The incentive isn't valuable enough to the referrer
- The ask appears before the user has experienced enough value
- The sharing mechanism is clunky or embarrassing
- The referred user gets no compelling reason to try it
- Rewards are delayed so long people forget

## Referral Program Design

### 1. Incentive Structure

Choose the incentive model that fits the product:

| Model | Best for | Example |
|-------|---------|---------|
| Both-sided reward | Consumer products with clear unit economics | "Give $10, get $10" |
| Referrer-only reward | B2B, high-LTV products | Credit, revenue share |
| Referred-only reward | Products where social proof matters | First-month discount |
| Non-cash reward | Community, values-driven products | Exclusive access, status |
| Tier-based | High engagement products | More rewards for more referrals |

Determine the maximum referral reward by: reward < (LTV × gross margin × CAC reduction factor)

### 2. The Right Moment to Ask

Never ask for a referral before the user has experienced value.
The best moments:
- Immediately after the "aha moment"
- After completing a milestone (first project, first month, first result)
- After a support interaction where the user expresses satisfaction
- At renewal (they just decided to stay — they're as happy as they'll be)

### 3. Referral Flow Design

Keep it under 3 steps:
1. User sees referral prompt → clicks "Share"
2. Unique link or code is generated → easy copy
3. Referred user signs up → reward triggered automatically

Referral link format: `domain.com/ref/[username]` (personal, memorable)

### 4. Referral Copy

**In-app prompt headline**: name the reward immediately
"Give a friend [X]. Get [Y] for yourself."

**Sharing copy** (pre-filled for the user — they edit, not write):
"I've been using [Product] for [duration] — it [specific outcome it delivered]. You can try it free: [link]"

**Email to referred user**:
- Subject: "[Friend's name] thought you'd like this"
- Body: social proof + the offer + what to expect
- CTA: "Claim your [reward] and get started"

### 5. Mechanics

- Unique tracking codes per referrer
- Real-time reward delivery (don't make them wait)
- Dashboard showing referral status and earnings
- Automatic emails at each stage (referral sent, accepted, reward earned)

## Output

Deliver: incentive model recommendation, referral flow spec, in-app prompt copy (3 variants), pre-filled sharing copy, and email copy for referred users.
