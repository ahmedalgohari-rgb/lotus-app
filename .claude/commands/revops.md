# RevOps

Analyze revenue operations and improve GTM processes for: **$ARGUMENTS**

## What This Skill Does

Bring revenue operations thinking to sales, marketing, and customer success alignment — identifying process gaps, data issues, and handoff failures that leak revenue.

## RevOps Scope

Revenue operations owns the intersection of:
- **Marketing operations** — lead generation, attribution, pipeline contribution
- **Sales operations** — pipeline management, forecasting, rep productivity
- **Customer success operations** — retention, expansion, churn prevention
- **Data and systems** — CRM hygiene, tech stack, reporting accuracy

## Diagnostic Framework

### 1. Revenue Pipeline Audit

Map the full customer journey with conversion rates at each stage:

`[Lead source] → MQL → SQL → Opportunity → Proposal → Closed Won → Onboarded → Retained → Expanded`

For each transition:
- What is the current conversion rate?
- What is the ideal conversion rate? (benchmark or target)
- What is the dollar value of improving by 10%?

### 2. Data Quality Assessment

CRM data issues that destroy forecasting accuracy:
- Duplicate records
- Missing required fields (company size, industry, source)
- Stale data (last activity > 90 days with no close date update)
- Inconsistent stage definitions across reps
- Attribution gaps (leads with no source)

### 3. Handoff Analysis

Where deals die between teams:
- **MQL → Sales**: Are MQLs being followed up within SLA? (benchmark: <5 minutes)
- **Sales → CS**: Is customer context transferred? Any drop in experience?
- **CS → Expansion**: Are expansion opportunities being identified and handed to sales?

### 4. Tech Stack Evaluation

Common bloat and gaps:
- Tools doing the same job (consolidation opportunity)
- Data not flowing between systems (integration gaps)
- Tools nobody uses (renegotiate or cancel)
- Manual processes that should be automated

### 5. Forecasting Accuracy

Evaluate current forecast methodology:
- What is the variance between forecast and actual close? (>20% is a problem)
- Are deal stages defined behaviorally or by rep judgment?
- Is historical conversion data used to weight pipeline?

## Output

For $ARGUMENTS: pipeline conversion audit, top 3 leakage points, data quality issues to fix, handoff process improvements, and a 90-day RevOps improvement roadmap.
