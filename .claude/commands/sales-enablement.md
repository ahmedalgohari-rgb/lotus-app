# Sales Enablement

Create sales enablement content and battle cards for: **$ARGUMENTS**

## What This Skill Does

Build the materials that help sales reps win more deals — competitive battle cards, objection handling guides, talk tracks, and proof points they can use in real conversations.

## Sales Enablement Assets

### 1. Competitive Battle Cards

One page per competitor. Format:

```
COMPETING AGAINST: [Competitor Name]

WHO THEY ARE
[2 sentences: what they do, their strongest appeal]

WHERE WE WIN
- [Capability 1]: We [do X]. They [don't / do Y which is worse because Z].
- [Capability 2]: ...
- [Capability 3]: ...

WHERE THEY WIN (be honest — reps need this)
- [Their strength]: Counter by [reframe or qualification question]

DISCOVERY QUESTIONS TO ASK
- "How important is [differentiator] to your team?"
- "Have you tried [their limitation] with [competitor]?"

LANDMINES TO PLANT
- "Ask them about [known weakness] — it'll come up in implementation"
- "Find out how they handle [edge case they struggle with]"

PROOF POINTS
- "[Customer] switched from [competitor] because [specific reason]"
- "[Metric] improvement after switching
```

### 2. Objection Handling Guide

For each common objection, provide:
- **The objection** (exact words prospects use)
- **What they actually mean** (the underlying concern)
- **The response** (acknowledge → reframe → evidence → question)
- **The trap response** (what not to say and why)

Common objection types:
- Price: "You're too expensive"
- Timing: "We're not ready to change tools right now"
- Competitor: "We're already talking to [X]"
- Risk: "We tried something like this and it didn't work"
- Authority: "I need to talk to my team / boss"

### 3. Discovery Talk Track

Questions that qualify and create urgency:
- Current state: "How are you handling [problem] today?"
- Impact: "What does it cost you when [pain point] happens?"
- Timeline: "What would need to be true to make a decision by [date]?"
- Decision process: "Who else needs to be involved in this decision?"

### 4. ROI Calculator Inputs

Fields reps need to complete a business case:
- Current cost (time, money, errors)
- Expected improvement percentage
- Deal size / annual contract value
- Payback period

## Output

For $ARGUMENTS: competitive battle card for top 2 competitors, objection handling guide for top 5 objections, and a discovery call talk track.
