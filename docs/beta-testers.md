## Testing Goals

### Success Criteria
- [ ] 5+ testers successfully onboard to TestFlight
- [ ] 20+ plants identified with no API errors
- [ ] 0 critical crashes (app-breaking bugs)
- [ ] Google & Apple Sign-In works for all testers
- [ ] Arabic localization displays correctly (RTL layout)
- [ ] Weather widget shows Cairo data accurately
- [ ] Plant collection saves and syncs properly

### Key Features to Test

**Priority 1: Core Functionality**
- [ ] Plant identification (camera + gallery)
- [ ] Plant saving to collection
- [ ] Care scheduling (watering, fertilizing, pruning)
- [ ] Authentication (Google, Apple, Guest mode)
- [ ] Navigation between screens

**Priority 2: Localization**
- [ ] Arabic language toggle works
- [ ] RTL layout displays correctly
- [ ] Plant names translate properly
- [ ] Care instructions in Arabic

**Priority 3: Edge Cases**
- [ ] Offline mode (airplane mode test)
- [ ] Low light plant photos
- [ ] Multiple plants in one photo
- [ ] Non-plant objects (should reject)

### Feedback Collection

**Ask testers to report:**
1. **Bugs:** What broke? Steps to reproduce?
2. **Confusion:** What was unclear or hard to use?
3. **Delight:** What did they love?
4. **Missing Features:** What did they expect but didn't find?

## Beta Testing Timeline

### Week 1: Internal Testing (Days 1-7)
- Day 1: Add 5-10 internal testers to TestFlight
- Day 2-3: Testers onboard and test core features
- Day 4-5: Collect feedback and identify critical bugs
- Day 6-7: Fix critical issues and push build 2

### Week 2: External Testing (Days 8-14)
- Day 8: Submit to external beta review (if needed)
- Day 9-10: Apple reviews and approves (usually 24 hours)
- Day 11-14: External testers test and provide feedback

### Week 3: Bug Fixes & Polish (Days 15-21)
- Day 15-17: Fix major bugs reported by testers
- Day 18-19: Push final TestFlight build (build 3 or 4)
- Day 20-21: Final verification testing

### Week 4: App Store Submission (Day 22+)
- Day 22: Submit v1.0.0 to App Store for review
- Day 23-25: Apple reviews app (1-3 days typical)
- Day 26: PUBLIC LAUNCH 🎉

## Notes

**Internal vs External Testers:**
- **Internal:** Instant access, no Apple review, up to 100 people, best for team/friends
- **External:** Public beta, requires Apple review (first time), up to 10,000 people, best for wider testing

**TestFlight Build Limits:**
- Each build expires after 90 days
- Up to 100 active testers per internal group
- Up to 10,000 active testers per external group
- Unlimited builds (but each takes ~20-30 minutes to process)

**Apple Beta Review (External Only):**
- First external build requires review (~24 hours)
- Subsequent builds auto-approve (if no major changes)
- Review checks: App works, no crashes, matches description
